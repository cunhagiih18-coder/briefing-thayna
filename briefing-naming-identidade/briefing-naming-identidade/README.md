# Briefing de Naming

Projeto responsivo em Next.js, preparado para publicação na Vercel.

## Publicar pela Vercel

1. Extraia este ZIP.
2. Envie a pasta para um repositório no GitHub.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório.
5. Mantenha o preset **Next.js** e clique em **Deploy**.

Não é necessário configurar variáveis de ambiente.

## Rodar localmente

Execute `npm install` e depois `npm run dev`.

Abra `http://localhost:3000`.

## Observação sobre o envio

O formulário preserva o preenchimento no navegador e exibe a confirmação final. O destino definitivo das respostas ainda precisa ser conectado a uma API, planilha, e-mail ou CRM.
